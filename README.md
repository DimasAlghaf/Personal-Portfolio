## ✦ About the Project

Welcome to my digital playground! This repository houses the source code for my personal portfolio. I built this not just as a resume, but as an interactive experience designed to showcase my passion for **stunning animations**, **fluid micro-interactions**, and **pixel-perfect UI/UX**.

## ✨ Magic Inside (Features)

This isn't your standard static page. Here is the magic happening behind the scenes:

- 🎭 **Choreographed Animations:** Powered by `framer-motion` for buttery smooth *fade-ins*, *spring transitions*, and a mesmerizing *random letter swap* on the navigation menu.
- 🌌 **Immersive Effects:** Custom `ParticleDrift` backgrounds and a `LoaderGlitchText` create a dynamic, futuristic feel.
- 🪞 **Glassmorphism UI:** Elegant, translucent blurs on the navbar that adapt seamlessly as you scroll down the page.
- 🛹 **Silky Smooth Scrolling:** Integrated with `Lenis` to override the clunky native browser scroll, giving visitors a premium gliding experience.
- 📨 **Direct-to-Inbox Contact:** Built-in form using `@emailjs/browser`—visitors can email me directly without leaving the site.

## 🛠️ Tech Stack

I selected a modern, lightning-fast stack to power this experience:

### Core
- **[React 19](https://react.dev/)** + **[Vite](https://vitejs.dev/)** for blazing-fast development and optimized builds.
- **[Tailwind CSS v4](https://tailwindcss.com/)** for rapid, utility-first styling without leaving the HTML.

### Motion & UI
- **[Motion (Framer Motion)](https://motion.dev/)** - The engine behind all the complex animations.
- **[Lenis](https://lenis.studiofreight.com/)** - For that premium scroll feel.
- **[Lucide React](https://lucide.dev/)** - Crisp, beautiful SVG icons.

### Utilities
- `clsx` & `tailwind-merge` - For clean and dynamic Tailwind class management.
- **[EmailJS](https://www.emailjs.com/)** - Serverless email handling for the contact form.

## 🚀 Run It Locally

Want to tinker with the code yourself? It's easy!

```bash
# 1. Clone the repository
git clone https://github.com/dimasalghaf/portfolio-react.git

# 2. Enter the directory
cd portfolio-react

# 3. Install the magic (dependencies)
npm install

# 4. Start the development server
npm run dev
```
*Then, open `http://localhost:5173` in your browser and enjoy the show!*
