# Dimas Ayyub Alghafiqi - Personal Portfolio ✨

Selamat datang di repositori portofolio pribadi saya! Portofolio ini dibangun dengan fokus pada **animasi yang memukau**, **performa tinggi**, dan **desain UI/UX yang modern**.

## 🚀 Fitur Utama

- **Animasi Interaktif**: Menggunakan `framer-motion` (Motion for React) untuk transisi yang halus, efek *fade-in*, *random letter swap* pada navigasi, dan efek interaktif pada teks.
- **Glassmorphism & Modern UI**: Desain minimalis namun elegan dengan efek *blur* (*glassmorphism*) pada *navbar* saat di-*scroll*.
- **Efek Partikel & Glitch**: Dilengkapi dengan komponen kustom seperti `ParticleDrift`, `LoaderGlitchText`, dan `AppleHelloEffect` untuk memberikan kesan futuristik dan dinamis.
- **Smooth Scrolling**: Terintegrasi dengan `Lenis` untuk pengalaman *scroll* halaman yang sangat mulus tanpa patah-patah.
- **Responsive Design**: Tampilan yang menyesuaikan dengan sempurna baik di perangkat *mobile*, *tablet*, maupun *desktop* (dibangun dengan Tailwind CSS).
- **Formulir Kontak Otomatis**: Menggunakan `@emailjs/browser` untuk menangani pengiriman pesan langsung dari halaman portofolio ke email saya.
- **Dark/Light Mode**: Mendukung pergantian tema gelap dan terang dengan komponen `ThemeToggle`.

## 🛠️ Teknologi yang Digunakan

Portofolio ini dikembangkan dengan *tech-stack* modern:

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + `clsx` + `tailwind-merge`
- **Animation**: [Motion (Framer Motion)](https://motion.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.studiofreight.com/)
- **Icons**: [Lucide React](https://lucide.dev/) & Iconify
- **Email Service**: [EmailJS](https://www.emailjs.com/)

## 📂 Struktur Proyek

Struktur komponen utama berada di dalam folder `src/components/`:

- `Navbar.jsx` - Navigasi interaktif yang berubah menjadi *glassmorphism* saat *scroll* dan animasi kemunculan foto profil secara perlahan.
- `Hero.jsx` - Bagian perkenalan utama (*landing section*) dengan efek teks interaktif.
- `About.jsx` - Informasi mengenai latar belakang saya.
- `Experience.jsx` - Riwayat pengalaman kerja profesional.
- `Projects.jsx` & `ProjectCard.jsx` - Daftar portofolio karya/proyek yang telah saya kerjakan.
- `SkillsCloud.jsx` - Visualisasi kemampuan (*skills*) yang saya miliki.
- `Contact.jsx` - Formulir kontak yang terintegrasi dengan EmailJS.
- `Footer.jsx` - Penutup halaman dengan tautan media sosial yang memiliki warna *hover* sesuai *brand* aslinya.
- `ui/` - Kumpulan komponen UI kecil dan kustom (seperti `RandomLetterSwap`, efek-efek transisi, dll).

## 💻 Instalasi & Menjalankan Proyek Secara Lokal

Jika kamu ingin menjalankan atau memodifikasi portofolio ini secara lokal, ikuti langkah-langkah berikut:

1. **Clone repository ini**
   ```bash
   git clone <url-repository-ini>
   ```
2. **Masuk ke folder proyek**
   ```bash
   cd portfolio-react
   ```
3. **Instal dependencies**
   ```bash
   npm install
   ```
4. **Jalankan server pengembangan (*development*)**
   ```bash
   npm run dev
   ```
5. **Buka di browser**
   Buka `http://localhost:5173` untuk melihat hasilnya secara langsung!
